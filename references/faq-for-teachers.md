# 给老师的常见问题（大白话版）

> 这份文档假设你**不熟悉电脑术语**。每条都是先给做法，再解释为什么。
> 程序里也有同一份（点右上角 **❓** 随时看）。

---

## 一、数据安全（最重要）

### 1. 我的数据存在哪？会不会丢？

存在**你这台电脑的浏览器里**（每个浏览器各自一份）。如果绑定过程序文件，每改一次还会**写进那个文件**。

全程不联网、不上传，别人看不到。

想更保险：点顶部 **⬇**，下载一份"数据包"存到 U 盘。

### 2. 为什么有时打开后提示「点一下恢复写入」？

浏览器规定：**每次重新打开页面，都要重新确认一次"写文件"的权限**。这是浏览器的安全机制，不是程序坏了。

做法：点「🔓 立即恢复写入」→ 弹窗里点"允许"。数据会自动补进文件，**不会丢**。

### 3. 教室电脑装了还原卡 / 冰点还原，第二天数据没了怎么办？

**每次开机后**：打开程序 → 点一次「🔗 绑定程序文件」→ 选中程序文件 → 允许。

这样当天的数据就写进文件里了。第二天双击这个文件，数据自己回来。

> 小技巧：把程序文件放在 **D 盘**（或桌面）一个固定文件夹里，别放在会被还原的地方。

### 4. 怎么知道数据保存好了？

看页面**右下角的小字**：

| 显示 | 含义 |
|---|---|
| `✓ 已写回文件` | 最安全，数据已在你的文件里 |
| `✓ 已自动保存` | 存在浏览器里（关机可能丢，建议绑定） |
| `⚠️ ...` 字样 | 有问题，点提示条上的按钮处理 |

### 5. 顶部弹出黄色 / 红色提示条怎么办？

看条上写的做法，**点条上的按钮**就行。

实在拿不准：**先点「🛟 导出数据包」存一份到桌面**。数据先保住，再慢慢处理。

### 6. 换了电脑 / 换了教室，怎么把数据带过去？

- **老电脑**：点顶部 **⬇** 导出数据包（.json），存到 U 盘
- **新电脑**：打开程序 → 出现"找回数据"面板 → 点「📂 打开数据包文件」，选中那个 .json

> 完整搬家：设置 → ④ 数据保存与找回 → 「📄 导出换机包」（生成一个带数据的 HTML，拷到新电脑双击即可）。

## 二、日常使用

### 7. 加分加错了怎么办？

- 撤销某一次：积分页点「↩ 撤销上一步」
- 清掉今天的：「↺ 重置今日积分」

### 8. 座位表怎么排？

- 直接**拖名字**换座位
- 工具栏有 **3 个方案槽**，可以存 3 套排法随时切换
- 点「轮换」可以按周自动轮换

### 9. 夏季 / 冬季课表怎么用？

点「☀️ 夏季课表」「❄️ 冬季课表」直接切换。

**第一次切到冬季，会按你当前的课表自动生成**——只调整升旗/上操的位置（夏季在第 1 节后、冬季在第 2 节后），其他课程不变。

手动微调后，点「💾 保存到 ❄️ 冬季课表」存好。

### 10. 上课要切 PPT，怎么快速收起？

点顶部 **⤓**：自动保存 → 退出全屏 → 缩到角落。点任务栏里的程序图标即可还原。

### 11. 怎么改班级名 / 主题配色？

- 班级名：**直接点页面顶部的大标题**就能改
- 配色：**⚙ 设置 → ② 配色主题**

### 12. 值日岗位 / 古诗 / 单词 / 题库在哪改？

都在 **⚙ 设置** 里：

| 想改什么 | 去哪 |
|---|---|
| 值日岗位 | ⚙ 设置 → ⑥ |
| 古诗库 | ⚙ 设置 → ⑨ |
| 计算题库 | ⚙ 设置 → ⑩ |
| 抽卡卡片 | ⚙ 设置 → ⑪ |
| 单词词库 | ⚙ 设置 → ⑫ |

## 三、还没解决？

1. 先点页面右上角 **❓**，看有没有答案
2. 还不行：**点「🛟 导出数据包」把数据存一份**（这一步最重要，数据保住了什么都好办）
3. 然后：把出问题的页面拍张照，发给帮你做这个程序的老师 / 或找 AI 助手，把照片发过去问

> 记住一件事：**只要数据包存下来了，程序怎么折腾都能恢复。**
